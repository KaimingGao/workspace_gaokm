# AkShare vs Tushare 日线对比报告

**日期**：2026-10-10  
**范围**：QuantLab 本地日线仓 `data/store/daily/CN/` vs Tushare Pro `daily`  
**样本**：`600519` · `000001` · `300750` · `000858` · `601318`  
**窗口**：约 2025-09 ～ 2026-08（各票以本地仓起止为准）

---

## 1. 结论摘要

| 维度 | 结论 |
|------|------|
| 交易日历 | 五只样本 **完全对齐**（无单边缺日） |
| 成交额 | 统一为「元」后 **一致**（Tushare `amount × 1000`） |
| OHLC | **同源可信**；差异来自复权口径，不是两套乱价 |
| 复权标签 | 本地仓标注 `qfq`，但 **3/5 票 OHLC 与 Tushare 未复权逐日全等**（实为 raw） |
| 涨跌幅 | 非除权日与 Tushare `pct_chg` 几乎重合；除权日 close/close 会偏离官方涨跌幅 |
| 成交量 | **存在「手 / 股」混用**；约 `2026-07-31` 起新条为股，更早段部分票仍为手 |

**一句话**：可以当作同一行情源的不同口径视图；工程风险在 **复权元数据不可信** 与 **成交量单位断裂**，不在「两边各编一套 K 线」。

## 2. 对比口径

### 2.1 AkShare 侧

- 来源：本地缓存，`data_source=akshare_cn_daily:qfq`，`adjust_policy=qfq`
- 拉取实现：`adapters/market/history.py` → `ak.stock_zh_a_hist(..., adjust=qfq|"" )`
- 字段：`date / open / high / low / close / volume`，有则保留 `amount`
- **现场限制**：审计时东财接口 `Connection aborted`，未能重拉直播 qfq/raw

### 2.2 Tushare 侧

- 接口：`pro.daily`（未复权）
- 单位换算（与 Ak 对齐时）：
  - `volume_股 = vol × 100`
  - `amount_元 = amount × 1000`
- **现场限制**：`pro_bar(adj='qfq')` 依赖 `adj_factor`，当前积分约 **1 次/小时**，未能完成 qfq↔qfq 全窗对照

### 2.3 判定规则

- 价格差：`|Ak − TS| > 0.01` 记为价差日
- 涨跌幅：`Ak_ret = close_t / close_{t-1} − 1`，对比 `pct_chg`（百分点）
- 除权日：`|TS.close_{t-1} − TS.pre_close_t| > 0.015`
- 量单位：`Ak.volume / (TS.vol×100)`；并用 `amount / (close×volume)` 交叉验证（≈1→股，≈100→手）

茅台分红在 Tushare `dividend` 中可核对（如 `20251219` cash_div≈23.96，`20260626` ≈28.02）。

### 3.2 解读

1. **「全等三只」**（茅台 / 宁德 / 平安）：整窗 OHLC 与未复权一致，但窗口内确有除权 → 缓存内容不是有效前复权，或拉取时 qfq 失败回退了 raw。  
2. **「qfq 两只」**（平安银行 / 五粮液）：除权前 Ak 价系统性低于 TS raw，除权后对齐，涨跌幅在 CA 日也与官方接近 → 更像真前复权。  
3. **非除权日**：两边日收益可视为同一序列（误差在浮点噪声级）。

## 5. 根因（工程侧）

### 5.1 qfq 标签与真实 adjust 可能不一致

`fetch_a_daily_bars` 对 A 股按 `("qfq", "")` 依次尝试；任一成功即返回。  
`fetch_daily_bars` 写入 `data_source=akshare_cn_daily:{请求的 policy}`，**不区分实际命中的 adjust**。  
因此：请求 qfq → 东财 qfq 失败 → 未复权成功 → 盘上仍标 `qfq`。这与「3/5 票 OHLC≡raw」一致。

### 5.2 增量合并导致量单位时间断裂

同一 JSON 内，旧段可能按「手」写入，`2026-07-31` 附近新拉条按「股」合并。  
成交额始终正确，故问题集中在 `volume` 字段语义，而非日期错位。

### 5.3 除权日收益算法差

- Tushare `pct_chg`：相对 **除权后 pre_close**  
- 简单 `close_t / close_{t-1}`：在 **未复权序列** 上会吃进分红/送转缺口  

仓内实为 raw 时，CA 日会出现数个百分点的「假差异」。

## 6. 对 QuantLab 的影响

| 用途 | 影响 | 建议 |
|------|------|------|
| 收益 / 动量 / 回测 | 非 CA 日可与 TS 互换；CA 日与复权路径敏感 | 固定一种复权；校验除权日 |
| Amihud / 换手 / 量能 | 手/股混用会数量级错误 | 统一为股后重算 |
| 缓存质量 / as-of | `adjust_policy=qfq` 不能当真理 | 记实际 adjust，或对 TS raw 抽检 |
| 多源融合 | 目前仓库日线主源仍是 AkShare；文档中的 Tushare 仅为成熟模型举例 | 若引入 TS，先统一单位与复权 |
