风控与敞口 · 拦截流水

来自纸面持仓实时敞口 + 最近 ops / 北极星拦截汇总

Alpha（进攻）

20 因子线性评分（19 生产权重）+ 因子择时 + 截面行业/规模残差 + 凯利仓位 + 技术确认

因子构成

  • 价量/趋势：动量、量价、技术形态、均线斜率、周线确认、相对强弱、特异动量
  • 风险/微观：波动、反转、流动性、跳空、非流动性（Amihud）
  • 基本面：估值、盈利收益率、质量(ROE)、成长、股息、规模
  • 情绪：另类情绪（小权重）；资金流已注册、默认权重 0
  • 截面：z-score 中性化 + 行业/规模残差（默认开）

因子择时

  • 牛市：启用动量、量价，禁用估值
  • 熊市：启用质量、流动性，禁用动量
  • 高波动：启用流动性、反转

凯利仓位

  • 根据胜率和盈亏比自适应
  • 高评分自动加仓，低评分减仓

技术指标确认

  • MACD趋势确认
  • KDJ超买超卖
  • RSI动量判断

Risk（防守）

动态止损 + 舆情风控 + 自适应阈值 + 相关性风控 + 成本控制

动态止损

  • ATR止损：基于波动率动态调整
  • 移动止损：盈利后跟踪最高价
  • 自适应：组合多种止损方式

自适应阈值

  • 胜率下降自动提高买入门槛
  • 连续亏损触发风控限制
  • 回撤控制仓位上限

相关性风控

  • 检测高相关性股票（>0.8）
  • 避免组合过度集中

交易成本

  • 精确计算佣金、印花税
  • 滑点成本预估
  • 真实收益评估

舆情风控

  • 强利空：评分 -5 分（触发减仓）
  • 弱利空：评分 -3 分
  • 利好：评分 +3 分（增强持仓信心）
  • 数据来源：观察页新闻情绪

调仓规则

加仓 + 梯度减仓 + 条件止损 + Walk-Forward优化

加仓

  • 评分 ≥ 60分，加仓 50%
  • 仓位大小由凯利公式自适应
  • 技术指标确认后加仓

梯度减仓

  • 评分 < 45分：减仓 80%（极弱）
  • 45 ≤ 评分 < 50分：减仓 50%（偏弱）
  • 50 ≤ 评分 < 60分：减仓 30%（中性偏弱）

条件止损

  • 亏损 ≥ 8%：全部卖出
  • 持有 ≥ 5天且趋势向下：卖出
  • 持有 ≥ 5天且趋势向上：继续持有

Walk-Forward优化

  • 滚动窗口参数优化
  • 参数鲁棒性验证
  • 定期自动调优
