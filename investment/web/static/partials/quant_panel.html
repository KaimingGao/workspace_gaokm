因子建议

IC / OLS 说明

默认用研究池第一只（常为 600519）日线做只读诊断。每个交易日 t 用截至当日的窗口跑 score_bars 取 sub_scores。结果不写 signal_config。

共同：前瞻收益

默认 horizon h = 3 个交易日：

rt→t+h = closet+h / closet − 1

（实现里乘 100 成百分比，相关/回归尺度一致即可。）

IC（单因子）

  1. 对每个因子 k，收集有值的日子：xt = 因子分，yt = rt→t+h。
  2. 样本数 n ≥ 3 且方差非 0 时，算 Pearson 相关：
ICk = corr(x, y)
     = Σ (xi−x̄)(yi−ȳ)
       / ( √Σ(xi−x̄)² · √Σ(yi−ȳ)² )

表中 IC / n 默认是单票时序 Pearson；无数字时显示原因标签： 缺测（n<3）· 常数（因子分无波动）· 收益平（前瞻收益无波动）。 点「截面 IC」改为池内日频截面（Pearson + Spearman）汇总，与单票 IC 不是同一指标。 页头「IC 12/20」= 20 个因子里 12 个算出了有效 IC。

OLS（多因子）

  1. 拼面板：每天一行「各因子分 + 前瞻收益」（允许缺测）。
  2. 筛因子：覆盖太少、几乎常数、或凑不齐完整行的剔除（「未入模」）。
  3. 在完整子面板上做多元线性回归：
y = β0 + β1x1 + … + βpxp + ε

OLS 列 ≈ β；无数字时显示原因标签： 缺测（覆盖不足）· 常数（几乎无波动）· 覆盖（为凑完整行剔除）· 共线（奇异剔除）；悬停可看说明。 R² = 1 − SSres/SStot； n = 完整样本行数。

两种模式：进页默认单票 walk-forward（快探针）。 「研究池 OLS」为显式触发：取观察名单前最多 8 只，把时序面板堆叠后再拟合（更稳一点）， 不是逐日截面 Fama–MacBeth，仍不写 config。跑完后摘要会列出实际入模代码。

OLS 系数 ≠ 生产权重

理想线性模型里，系数与权重方向一致： 

r̂ = β0 + Σ βk xk
  ⇒  score ∝ Σ βk xk

因此「用 β 当线性打分权重」在理论上说得通。但本页不会把 raw OLS 系数直接写成 signal_config.weights：

  1. 尺度：生产权重是归一化、常带非负/上限约束的配置；β 可正可负、可任意大，量纲是收益贡献，不是占比。
  2. 稳定性：样本少或因子共线时 β 易抖（例如 IC 为正而 OLS 为负）；表上的「建议 / Δ」走 IC 小步调整，更适合人审迭代。
  3. 目标：OLS 拟合历史前瞻收益；生产权重还要可解释、风控、缺测与未入模因子。
  4. 边界：研究建议 ≠ 自动写盘。若要用回归思路调权，路径应是 β → 归一化/裁剪 → OOS 验证 → 人审 promote，而不是把 OLS 列原样当权。

表里把 OLS 与「当前 / 建议」并排，是为了对照诊断：权重建议来自 IC / weight_suggest；OLS 用来看联合后谁还剩解释力。

怎么用

先看 IC 筛有用因子 → 再看 OLS 联合后谁还剩贡献 → 对照「当前 / 建议 / Δ」导出 diff → 人审后再改配置。IC 强而 OLS 弱时慎加权重；R² 低或未入模很多时，优先看横截面与回测，勿只靠单票拍板。
