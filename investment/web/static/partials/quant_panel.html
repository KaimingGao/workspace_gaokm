因子建议

IC / OLS·Ridge / 建议权重说明

默认用研究池第一只（常为 600519）日线做只读诊断。每个交易日 t 用截至当日的窗口跑 score_bars 取 sub_scores。结果不写 signal_config。

共同：前瞻收益

默认 horizon h 来自本页控件（可「存为默认」写入 memory.json）；不改数据中心评分 / 交易执行。 常用 h = 3 个交易日： 

rt→t+h = closet+h / closet − 1

（实现里乘 100 成百分比，相关/回归尺度一致即可。）

IC（单因子）

  1. 对每个因子 k，收集有值的日子：xt = 因子分，yt = rt→t+h。
  2. 样本数 n ≥ 3 且方差非 0 时，算 Pearson 相关：
ICk = corr(x, y)
     = Σ (xi−x̄)(yi−ȳ)
       / ( √Σ(xi−x̄)² · √Σ(yi−ȳ)² )

表中 IC / n 默认是单票时序 Pearson；无数字时显示原因标签： 缺测（n<3）· 常数（因子分无波动）· 收益平（前瞻收益无波动）。 点「截面 IC」或截面驱动建议时，改为池内日频截面（Pearson + Spearman）汇总，并出现 ICIR 列；与单票 IC 不是同一指标。 页头「IC 12/20」= 20 个因子里 12 个算出了有效 IC。

ICIR（截面稳定性）

ICIR = Information Coefficient Information Ratio（信息系数的信息比率）。 对研究池逐日算截面 IC，再对这串日 IC 求： 

ICIR = IC̄ / σ(IC)
     = mean(日截面 IC) / std(日截面 IC)

IC 看某一天（或均值）相关强弱； ICIR 看预测力是否既偏正/偏负又稳（均值大、波动小）。 |ICIR| 大更可信；接近 0 表示弱或不稳。 权重建议的强证据要求 |IC| ≥ 0.03 且 |ICIR| ≥ 0.25，并用 |ICIR| 缩放步长。 单票时序 IC 通常没有 ICIR（表里为 —）。

OLS / Ridge（多因子线性回归）

研究探针上的多元线性回归：拟合因子分 → 前瞻收益。 目标默认是残差平方和（与 MSE 只差常数 \(1/n\)，最优点相同）： 

minβ  Σi (yi − ŷi)²
ŷi = β0 + β1xi1 + … + βpxip

求解（本页）：不再用「正规方程 + 高斯消元」。 ridge λ = 0 时对设计矩阵做 QR 再回代；奇异则剔共线列重试。 

X = QR
R β = Qᵀ y
（相对 XᵀX β = Xᵀy，条件数不平方，数值更稳）

ridge λ = λ > 0 时为 Ridge（L2）：斜率收缩、截距不惩罚， 缓解共线 / 小样本过拟合，尽量保留入模因子。 

minβ  ||y − Xβ||² + λ Σk≥1 βk²
实现：Tikhonov 增广 [X; √λ I斜率] 后再 QR
（λ 取本页「ridge λ」，范围 0～100）

OLS / Ridge 计算步骤（本页）

  1. 拼面板：每个交易日（或池内堆叠后的每一行）取 因子分 + 前瞻收益 \(y=r_{t→t+h}\)（百分比）。研究路径全量注册因子， 不经 regime 白名单；允许缺测。
  2. 筛列 / 筛行：覆盖太少、几乎常数、凑不齐完整行的因子剔除 （表上「缺测 / 常数 / 覆盖」）； λ=0 时 QR 秩亏继续剔列（「共线」）； λ>0 时尽量保留入模列。
  3. 标准化（默认开）：对入模列做样本内 z-score， \(x'=(x-\bar x)/\sigma\)。于是表上的 β ≈「该因子高 1σ 时， 前瞻收益变多少个百分点」；勿与 config 权重同量级对比。
  4. 拟合：按本页 ridge λ 选 QR OLS 或 Ridge， 得 \(\beta_0,\beta_1,\ldots,\beta_p\)；摘要可见 QR / Ridge λ=…。
  5. 指标： \(R^2 = 1 - SS_{res}/SS_{tot}\)（用拟合值算，Ridge 时仍是样本内 R²）； n = 完整样本行数； OLS 列 = 各因子 \(\beta_k\)（未入模显示原因标签）。 
y = β0 + Σk βk x'k + ε
SSres = Σ (y − ŷ)²
SStot = Σ (y − ȳ)²

两种模式：进页默认单票 walk-forward（快探针）。 「研究池 OLS」：观察名单前最多 8 只，时序面板堆叠后再拟合 （非逐日截面 Fama–MacBeth）。均不写 config。 无 Lasso（L1）；L2 仅当 ridge λ > 0。

当前 / 建议 / Δ（权重建议）

表里当前来自 signal_config.weights； 建议默认由研究池截面 IC / ICIR驱动（池不足回退单票时序 IC）， 弱证据再回退 OLS / 近零降权。详见 docs/weight-suggest-deepen.md。

  1. 强截面证据：日数 n 足够， |IC| ≥ 0.03 且 |ICIR| ≥ 0.25 → δ = sign(IC)·0.03·scale， scale = clamp(|ICIR|/0.5, 0.5, 1.5)。
  2. 否则 OLS：入模且 |β| ≥ 0.05 → 按符号 ±0.02。
  3. 再否则：有 IC 但未过 IC/ICIR 门槛 → −0.015（证据不足略降权）。
  4. 夹紧后归一化 →「建议」；Δ 悬停可见证据来源。 
强证据: |IC|≥0.03 且 |ICIR|≥0.25
δ = sign(IC)·0.03·clamp(|ICIR|/0.5, 0.5, 1.5)
否则: OLS ±0.02 或 近零 −0.015
建议 = normalize(clamp(w+δ))

单票回退时无 ICIR，仅按 |IC| 判强证据。 冲突时以强 IC/ICIR 为准。 另施加：零权冻结（如 money_flow）、 组内上限 45%、regime 白名单外上调提示。

OOS 门禁（P2）

默认对「当前权 vs 建议权」各跑一遍研究池 Top-K（后 30% 权益为 OOS）。 过门：建议 OOS ≥ 当前 OOS − 1pp，且不新增 OOS 失败旗标 → promote_ready=true（仍须人审，不自动写盘）。 未过 / 跳过时导出 diff 会二次确认。

OLS / Ridge 系数 ≠ 生产权重

回归最小化的是历史前瞻收益误差（Ridge 时再加斜率 L2），得到的是偏效应 β，不是归一化权重。 建议不会把 raw β 写成 signal_config.weights： 弱 IC 时只用 β 符号做小步 ±0.02；表内 OLS 列仍显示原始 β 供对照。

怎么用

优先看截面 IC/ICIR → OLS →「建议 / Δ」导出 diff → 人审； 上线前用回测 / OOS 验证。
