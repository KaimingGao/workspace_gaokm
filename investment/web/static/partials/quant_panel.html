ŷ_EOD

组 β 聚类 · 主轴排序 / 买入

参数就绪 · 点「跑分组」

? 说明

目的：找出 OLS 表现相似的股票，同组共用一套因子系数； 不同组各自池 OLS → 各自 β → 收益分 ŷ_EOD（主轴），避免异质票硬套全局模型。

「跑分组」：宇宙=观察池前 Limit 只（默认 100≈满池），按单票 OLS β 层次聚类。 表单默认 ridge λ=1.0、K=自动（中心约 N/5，夹在 4～10；宇宙日历前段 β 定组；邻域 ±1 × 多折均值尾段 ŷ IC / 前段重拟合选优；定组后有限轮 holdout 贪心换组；另附扩展窗审计；超大组再二分）； 填 ≥2=按目标 k 切簇（尽量贴近 K；实际上限≈有效票数，不因离群拆成单票堆）。

双层 ŷ

本组只产 ŷ_EOD。ŷ_τ（当日剩余 / τ Ridge）在独立「ŷ_τ」区块拟合与启用，不进聚类、不改组 β。

OOS 语义

基线：全局人工预定义线性加权（heuristic_score）。研究臂：本页回归模型 → predicted_score（ŷ_EOD）。

因子系数 β

分组后为一组一表。表里系数 β来自该组池 OLS，即 return_model.coefficients，驱动组内收益分 ŷ_EOD。

耗时（满池 ≈100 只 · K=自动）

全量重算常见 30～45+ 分钟（有心跳可持续等到约 90 分钟；命中 24h 缓存则秒级）。 钱主要花在选区，不是卡死：

  • ~15% 拉日线 + 单票拟合 + β 矩阵（约 5～8 min）
  • ~55% auto-k 选区：邻域 k×配方串行，每步聚类 + holdout 打分（约 15～25 min，6 步）
  • ~5% 组池 OLS + 贪心换组
  • ~15% 组内 OOS 闸门（按组串行，约 20～30 s/组）
  • ~10% 组内打分 / 分池合成 / 收尾（分池对照回测用全局 heuristic，不应再拖数十分钟）

想快：缩小 Limit（20～40）、或填固定 K（跳过选区网格）。 日线：先在上方「日线」区更新到最新，或当日第一次跑分组自动强更；同日再跑分组用本地缓存（改参更快）。 大宇宙（≥40）已关逐日 PIT / Ridge 搜 λ / 扩展窗多折，但仍保留选区网格。

ŷ_τ

open→close τ Ridge · 副轴 / τ 闸

待命 拟合后看 OOS · 过门再启用
? 说明

ŷ_τ = τ Ridge，标签 close[T]/open[T]−1；字段 predicted_score_tau（= ŷ_τ；旧别名 score_rem 可读）。 特征另含 PIT 历史真实开→收 tau_lag1（上一交易日）、 tau_ma5（过去最多 5 日均值）；标签仍是当日 close[T]/open[T]−1。改特征后请重新拟合。

不进聚类、不改 ŷ_EOD。启用后只影响主题日 soft hold / τ 闸；表列主分仍是 ŷ_EOD。 融合权重与 τ 闸在 策略中心 · 融合分数 （仅 blend）。分钟**训练**网格含开盘 Z + 午后训练钟 09:30|09:35|…|11:00（09:30 无前缀；早盘每 5m 共享 β；不含 13:00 / 14:00；**做T执行 v6 收盘带宽**：每 5m 扫至 11:00，收价破 ĉ±δ 开 leg1，path 不进 ĉ）；live 调仓钟仍是 10:30。

ŷ_ON

open[T+1]/open[T]−1 · 隔夜链 Ridge · 风控旁路

待命 拟合后看 OOS · 过门再启用
? 说明

ŷ_ON = 隔夜 open 链 Ridge，标签 open[T+1]/open[T]−1；字段 predicted_score_on。

不进主排序、不改 ŷ_EOD / ŷ_τ。用于收盘前评估「今开→明开」路径；后续可接缩仓闸。 与 gap_pct（收→开缺口）勿混名。

ŷ_path

极值序 · 多 τ 共享 β · 画像对照 · 需分钟缓存

待命 拟合后看 OOS · 过门再启用
? 说明

ŷ_path = 开盘 Z + 早盘前缀分钟小包 → 全日极值序 signed range% （先低后高为正）。训练默认多 τ 网格 09:30|09:35|…|11:00 （**做T执行 v6 收盘带宽**扫至 11:00；不含 13:00 / 14:00）共享 β，看 OOS by_tau；live 调仓决策钟默认 10:30。 字段 y_path / predicted_score_path。 特征另含 PIT 历史真实极值序 path_lag1（上一有 5m 的交易日）、 path_ma5（过去最多 5 个有 5m 日的均值）；标签仍是当日全日极值序。 改特征后请重新拟合。

与做 T 的关系：ŷ_path 进回测画像命中对照， 不进 v6 收盘带宽的 `ĉ`。选正/反 T 看收价破 `ĉ±δ`。 落盘 path_ridge_model.json；配置见 交易执行 · 做 T 规则。

依赖观察池 5m 分钟缓存；无分钟线时会报错。可在上方「分钟线」区块点 强更 5m。

ŷ_cx

曲折度 · 1−D/L ∈[0,1] · 多 τ 共享 β · ŷ_cx>门槛跳过

待命 拟合后看 OOS IC / 中位命中 · 过门再启用
? 说明

ŷ_cx = 开盘 Z + 早盘前缀分钟小包 → 1 − D/L（∈[0,1]）。 D 为全日 5m 收价首末位移， L 为相邻 5m 路径长（午休跳空不计入）。 0 = 直线（最低），1 = 最折。 不是波动率：单边趋势可以振幅大但曲折度低。 字段 y_cx / predicted_score_cx。 特征另含 PIT 历史真实曲折度 cx_lag1（上一有 5m 的交易日）、 cx_ma5（过去最多 5 个有 5m 日的均值）；标签仍是当日全日 1−D/L。

标签无符号，OOS 看 Spearman IC 与 中位命中 （≈50% 即无排序信息），不看方向命中。 独立 y_spec，不写 predicted_score / ŷ_τ / ŷ_path。 落盘 cx_ridge_model.json。 做 T：盘中前缀 ŷ_cx > y_cx_max（0.01–1.00，默认 1.00≈关）则跳过；改标签尺度后请重新拟合。

依赖观察池 5m 分钟缓存；无分钟线时会报错。可在上方「分钟线」区块点 强更 5m。
