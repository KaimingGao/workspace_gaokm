分组

IC / OLS·Ridge / 建议权重说明

目的：找出 OLS 表现相似的股票，同组共用一套建模/配权； 不同组各自池 OLS → 各自建议权，避免异质票硬套全局权。

「跑分组」：宇宙=全部观察池，按单票 OLS β 层次聚类到目标组数（约 N/5，4～10），超大组再二分； 一组一表标题含成员（名称+代码）与当前 / 建议 / Δ · 组内 OLS β。 异质用探针核对。数据不足单独提示。均不写全局 config。

当前 / 建议 / Δ（权重建议）

分组后为一组一表。表里当前来自 signal_config.weights； 建议来自该组池 OLS 小步草案（异组不同）。 详见 docs/weight-suggest-deepen.md。

探针（单票 vs 所在组）

选一只票，算其时序 IC 与 OLS β，并与所属组对照。 若 |ΔIC| 或 |Δβ| 偏大，说明不宜与该组共用建模，应视为离群或换组。
