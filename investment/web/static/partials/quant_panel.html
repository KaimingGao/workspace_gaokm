ŷ_oo

open(T)→open(T+1) · 组 β 聚类 · 主轴排序 / 买入

参数就绪 · 点「跑分组」

? 说明

目的：找出 OLS 表现相似的股票，同组共用一套因子系数； 不同组各自池 OLS → 各自 β → 收益分 ŷ_oo（主轴），避免异质票硬套全局模型。

「跑分组」：宇宙=观察池前 Limit 只（默认 200≈满池），按单票 OLS β 层次聚类。 表单默认 ridge λ=1.0、K=自动（中心约 N/5，夹在 4～10；宇宙日历 Holdout 前段 β 定组；邻域 ±1 × 多折均值尾段 ŷ IC / 前段重拟合选优；定组后有限轮 holdout 贪心换组；另附扩展窗审计；超大组再二分）； 填 ≥2=按目标 k 切簇（尽量贴近 K；实际上限≈有效票数，不因离群拆成单票堆）。 页顶 Holdout日 同时切定组与研究套组 β（执行套仍全样本；EOD 研究 β 再隔离 horizon）。

双层 ŷ

本组只产 ŷ_oo。ŷ_oc（当日剩余 / τ Ridge）在独立「ŷ_oc」区块拟合与启用，不进聚类、不改组 β。

OOS 语义

基线：全局人工预定义线性加权（heuristic_score）。研究臂：本页回归模型 → predicted_score（ŷ_oo）。

因子系数 β

分组后为一组一表。表里系数 β来自该组池 OLS，即 return_model.coefficients，驱动组内收益分 ŷ_oo。

耗时（满池 ≈200 只 · K=自动）

全量重算常见 15～30 分钟（有心跳可持续等到约 90 分钟；命中 24h 缓存则秒级）。 钱主要花在定组后组内 OOS，不是卡死：

  • ~15% 拉日线 + 单票拟合 + β 矩阵（约 5～8 min）
  • ~20% auto-k 选区：邻域 k×配方 + holdout；文案会报「估β / 打分 i/n」。满池（≥40）跳过组权 OOS 辅门禁（约 2～8 min，6 步）
  • ~5% 组池 OLS + 贪心换组
  • ~50% 定组后组内 OOS 闸门（按组串行，两臂 Top-K）。文案会报「基线 / 研究臂 · 日期 i/n」，百分比约 62～90%。闸内不拉分钟/ŷ_oc、日线截到 lookback（大约每组几十秒）
  • ~10% 组内打分 / 分池合成 / 收尾（分池对照回测用全局 heuristic，不应再拖数十分钟）

想快：缩小 Limit（20～40）、或填固定 K（跳过选区网格）。 日线：先在上方「日线」区更新到最新，或当日第一次跑分组自动强更；同日再跑分组用本地缓存（改参更快）。 大宇宙（≥40）已关逐日 PIT / Ridge 搜 λ / 扩展窗多折 / 选区组权 OOS，仍保留选区网格。
