研究用 Top-K 回测净值（非纸面账本；权重可选等权/分数预算/风险平价）。起点 100；每完成一期持有（默认 3 日）按组合收益复利更新。选股按 ŷ_EOD，关 ŷ_τ 闸（与 live ŷ_trade 不同）。单线=当次回测；对照时蓝=中性化、绿=绝对分。

说明

回测怎么跑 · lookback / horizon

lookback＝样本长度（默认 120 个共同交易日）； horizon＝持有几个交易日再调仓（填 1＝每个交易日一轮，不是日历自然日）。

因子权＝全局 signal_config.weights（固定，非分组权）； 池＝观察池 − exclude（验证宇宙），不是纸面持仓。 页上「等权 / 分数预算」是股票仓位，不是因子权。

分数口径：本页只有日线，不含可靠 ŷ_τ。Top-K 按 ŷ_EOD（predicted_score）从高到低选取，并 关闭 ŷ_τ 买入闸。live 调仓才用 ŷ_trade / τ 闸——勿把本页成交表当成 live 融合分。

  1. 准备：拉日线对齐；净值从 100 起；读一次全局因子权。
  2. 攒历史：前若干日只积累窗口（约需 ≥12 根），不买卖。
  3. 信号日：对池内每票用「当天及以前」K 线打 ŷ_EOD（可中性化）→ 取 Top-K（默认 3）。
  4. 次日开盘（默认 next_open）：假买入；持有 horizon 个交易日。
  5. 出场：按规则卖出 → 加权收益 − 换手成本 → 更新净值。
  6. 下一轮：指针前进 horizon 天，重复打分→买入→持有→卖出，直到样本不够。

horizon=1 时：每个交易日都可成为信号日，调仓更密、成本更重。
