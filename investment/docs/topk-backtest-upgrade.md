# TopK 回测优化升级规划（T 轨）

[← 文档索引](README.md) · 专业差距见 [strategy-validation-upgrade](strategy-validation-upgrade.md) · 产品边界 [design-spine](design-spine.md#产品边界现行) · Web [quant-ui](quant-ui.md)

**规划日期**：2026-07-30 · **深化补强**：2026-07-30（第二程）  
**定位**：把「观察池 TopK 等权回测」从**偏惩罚/口径易误解**抬到**研究结论可严肃使用**；服务策略验证，**不**开 OMS / Tick 仓。  
**与 V 轨关系**：第一程（T0–T4）加深 [V1 成本与撮合](strategy-validation-upgrade.md#5-v1--成本与撮合诚实度)；第二程（T5–T8）补「有效性 vs 正确性」证据链，对齐专业 TopK / 分层 / IC 叙事（仍限策略验证边界）。

---

## 0. 一句话目标

**第一程（已收口）**：同一观察池、同一 `score_bars` 下，含成本回测反映真实换手摩擦，并与纸面 `simple_cn`、live 特征边界可读对齐。

**第二程（已收口）**：让用户无法只靠「累计收益为正」下结论——必须能回答：打分有没有区分度（IC/分层）、相对基准有没有超额、换手形态是否可执行、宇宙是否滤掉垃圾股动量坑——再进入纸面小仓。

## 1. 差距摘要

### 1a · 相对专业系统（第一程）

| 优先级 | 缺陷 | 污染 | 状态 |
|--------|------|------|------|
| **P0** | 每期全仓往返成本 / 费率不一致 | 含成本结论不可信 | **T0/T4 已收** |
| **P1** | live（舆情/门禁）≠ 回测日线口径 | 回测–纸面落差 | **T1 脚注已有；T8 加深感知** |
| **P2** | 小宇宙 + 共同日裁剪；归因浅 | 外推高估 | **T2 宇宙披露；T6/T7 继续** |
| **P3** | 无完整 QP / Barra / Tick | 机构级不足 | **锁定不做（策略验证阶段）** |

### 1b · 相对「专业 TopK 叙事」的第二程缺口

| 优先级 | 缺口 | 污染 | 目标阶段 |
|--------|------|------|----------|
| **P0** | 无分层/分位数回测；IC 与 TopK 页割裂 | 头部偶然赚仍过关；有效当正确 | **T5 已收** |
| **P0** | 缺指数基准与超额 / IR | beta/题材当 Alpha | **T6 已收（超额%；IR/双线可选）** |
| **P1** | 无 TopK-Dropout（K±N 缓冲） | 换手与主流量化形态不符 | **T7 已收** |
| **P1** | 回测宇宙缺流动性/ST/质量硬过滤 | 垃圾股动量溢价、成交幻觉 | **T7 已收** |
| **P2** | 滚动稳健 / 参数钝感弱；页内感知弱 | 过拟合捷径、误推 live score | **T8 已收** |

## 2. 阶段总览

```text
【第一程 · 已收口】
T0  成本诚实度          ✓
T1  口径与报告诚实      ✓
T2  宇宙与统计纪律      ✓
T3  组合层权重          ✓
T4  CostPort 架构稳态   ✓

【第二程 · 深化补强】
T5  信号纯度（IC 门禁 + 分层回测）     ← 下一刀优先
        │
        ▼
T6  Alpha 诚实（基准超额 · IR）
        │
        ▼
T7  执行形态（Dropout · 流动性/ST 过滤）
        │
        ▼
T8  稳健与感知（滚动窗 · 钝感 · 文案 · 纸面衔接）
```

**架构原则（第二程仍遵守）**：

- 不重写整引擎；在 `topk_backtest` / `quant_service_replay` / 绩效分析页增量。  
- 生产 Alpha 仍为可解释线性 `score_bars`；IC/分层是**验证面**，不上 NN 生产分。  
- 宇宙默认仍是 watching / `validation_universe`（非全市场）；过滤是**池内硬化**，不是假装全 A。  
- 改参仍走人审 promote；禁止静默写 `signal_config`。
