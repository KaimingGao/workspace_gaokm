# 量化研究台说明书（Web）

[← 文档索引](README.md) · **产品主轴**见 [design-spine.md](design-spine.md) · 原理见 [quant.md](quant.md) · 运维见 [quant-ops.md](quant-ops.md)

**产品定位**：本 Web 是 **策略验证台**——观察名单、回测、**模拟账户**交易与 AI 命令；**现行不涉及真实账户交易**，一切买卖只记在本地纸面账本（假钱），用于策略与流程验证。待验证成熟后再评估实盘（N6）。边界见 [design-spine · 产品边界](design-spine.md#产品边界现行)。

**壳层**：侧栏六业务模块 + 顶栏「AI 助手」（⌘K）见 [quant-ui-refactor-plan.md](quant-ui-refactor-plan.md)。首页 `/` 重定向数据中心；**全屏对话 `/chat` 已下线**（→ `/watching`）。默认浅色，A 股红涨绿跌。升级落地进度见 [quant-ui-upgrade.md](quant-ui-upgrade.md)。

图表：观察 / 仪表盘 / 模拟 / 回溯已接 **Lightweight Charts**（十字线 · MA）。回溯报告含成本假设与归因表；页内「回测怎么跑」折叠说明 lookback/horizon 日程；可跑 **参数扫描热力** 并 **导出研究包 / 回测报告**。策略页有策略卡晋升与因子字典；选股因子系数在研究枢纽。全局 **⌘⇧K** 命令面板跳转（含密度 / 分屏 / 实况）。顶栏 **告警铃**（可授权浏览器通知）。系统设置有 **审计时间线** 与 **产品北极星 KPI**（滚动夏普/卡玛 · 回测–纸面 Corr/TE · TTM；`GET /api/north-star`）。接口失败时顶栏下有红色降级条。仪表盘净值可走 **React 岛**（CDN 失败自动回退）；观察页可 **表|图分屏**；全站 **`/ws/live` 实况** 推送纸面指标并轻量刷净值；顶栏可切 **紧凑密度**；观察/模拟主表为 **虚拟滚动**（预算 500 行；岛失败时回退分页）。

**产品聚焦三件事**（观察 ≠ 模拟）：

1. **观察** — 维护要长期看的股票名单，并从这里**建仓**进模拟；对话做解读与问答  
2. **模拟** — 已有仓位的**账本与管理**（加减仓 · 清仓 · 净值曲线）  
3. **回溯** — 对着历史交一卷  

**一条贯穿的原则**：谁决定「买什么、买多少」，就归谁。你决定的走主路径；规则决定的收进「进阶」，并在持仓上标出处。

## 用户心智与验证闭环

系统定位是 **策略验证台（假钱）**。用户常只感知到两件事——这与主路径一致，但容易**高估「验证」的严格程度**：

| 常感知目标 | 页面动作 | 真实含义 |
|------------|----------|----------|
| 不定期手动策略调仓，对比 `short` / `short_conservative` | 交易执行 · 策略调仓 → 预演 → 确认 | **纸面流程验证**；应再对照历史回测、五问、风控、北极星拟合 |
| 做 T 回测验 T 策略 | 交易执行 · 做 T 回测（及预演/确认） | **底仓 overlay 验证**，不是独立选股 Alpha |

推荐闭环（侧栏顺序即引导顺序的一种读法）：

1. **数据中心** — 选池、看评分/倾向、人工建仓  
2. **历史回测** — Top-K / WF / 成本：先问「历史上这套规则是否像样」  
3. **交易执行** — 手管仓 + 策略调仓 + 可选做 T：问「纸面能否落地」  
4. **策略中心** — 改限额/持有期 → **人审晋升**（不静默写盘；选股 β 在研究枢纽）  
5. **系统设置** — 北极星（夏普/卡玛 · Corr/TE · TTM）、审计、调度健康  

**易漏能力**：调仓五问与纸面日更；账户风控提示/拦截；告警→配置建议；回测参数扫描与导出研究包；AI 只解读不改分；持仓出处（手动/策略）。

产品主轴长文见 [design-spine · 用户心智与验证闭环](design-spine.md#用户心智与验证闭环现行)。

设计主轴（数据→信号→因子→倾向→动作 · 量化主轴 vs AI 旁路）见 [design-spine.md](design-spine.md)。  
**改 UI 契约**（页面唯一任务 · 组件白名单 · 验收清单 · `ASSET_V`）见 **[quant-ui-standard.md](quant-ui-standard.md)**。

进阶能力集中在侧栏 **研究枢纽**（`/quant`：因子 · 运维 · 日报）；`/paper` 仍有路由并重定向到 `/follow`。  
AI 只解读，**不得改写** `score` / `stance_label`。

名词见 [quant-concepts.md](quant-concepts.md)。

## 主路径页面

| 路径 | 对应需求 | 说明 |
|------|----------|------|
| `/watching` **数据中心** | 长期名单 + 建仓入口 | 搜票加入；现价/涨跌；评分·倾向等；建仓记录 |
| `/follow` **交易执行** | 已有仓位管理 | 持仓加减仓 · 清仓 · 净值曲线（**不**开仓） |
| `/replay` **历史回测** | 历史回测 | Top-K 回测指标、Walk-forward、成交样本 |
| `/strategy` **策略中心** | 规格与晋升 | 策略卡限额 · 人审 promote · ŷ 滞回说明 |
| `/quant` **研究枢纽** | 因子 · 运维 · 日报 | 侧栏主入口；不自动写生产配置 |
| `/platform` **系统设置** | 平台配置 | 记忆 · 调度 · 审计 |
| AI 抽屉（⌘K） | 解读 · 问答 · 命令 | 顶栏「AI 助手」；**全屏 `/chat` 已下线** |

独立工具页：左侧六模块导航；顶栏为环境/时钟/状态。AI 入口仅为抽屉，不再提供全屏对话页。

## 仪表盘

路径：`/dashboard`（`/` 重定向至此）。**唯一任务**：开盘报告式态势感知——市场、纸面 KPI、风险、净值、仓位/信号，**不负责买卖**。看完再去数据中心 / 交易执行 / 策略中心动手。

设计逻辑与设计语言（改 UI 时遵守）见 [quant-ui-standard · 仪表盘](quant-ui-standard.md#仪表盘)。

### 主要功能（从上往下）

1. **概览**  
   指数 / 涨跌家数 / 持仓市值 + 纸面 KPI（今日/累计收益、Sharpe、最大回撤、胜率）。  
   收益用 **A 股红涨绿跌**；Sharpe/胜率等质量指标用绿/红告警语义（非涨跌色）。

2. **风险**  
   摘要条（VaR / Sharpe / 回撤 / 集中度等）+ 年化收益/波动 / Sortino / Calmar。

3. **净值路径**  
   累计净值曲线（起点 100）；可勾选对比沪深300；区间 30D / 90D / YTD / ALL。约 90 秒自动刷新。

4. **风险分解**  
   回撤曲线 · 历史 VaR 直方图 · 持仓板块热力。

5. **仓位与信号**  
   资产配置（横向条带）· 板块暴露 · 最新信号 · 策略卡列表。

### 怎么看一屏（约 30 秒）

| 顺序 | 问自己 | 看哪里 |
|------|--------|--------|
| 1 | 市场与持仓广度怎样？ | 概览行情卡 |
| 2 | 账赚钱了吗？回撤/夏普是否失控？ | KPI + 风险 |
| 3 | 净值最近在爬还是在掉？ | 净值路径 |
| 4 | 尾部风险与板块结构？ | 风险分解 |
| 5 | 仓位集中在哪？有什么信号？ | 仓位与信号 |

### 边界（避免误用）

- **不能**在仪表盘下单或改名单；动作去侧栏对应模块。  
- 曲线依赖交易/日更产生的快照；空仓时曲线可能为空。  
- 约 90 秒自动刷新；也可点页头「刷新」。

## 操作流程（照着做）

```text
① 启动 → ② 观察名单放几只票 → ③ 对话解读
        → ④ 回溯看历史表现 → ⑤ 纸面初始化 → ⑥ 模拟买卖几天
```

### ① 启动

```bash
cd investment
python3 -m pip install -r requirements.txt
bash scripts/setup_quant.sh   # 可选：观察名单 + 纸面
python3 run_web.py
```

打开 `http://127.0.0.1:8000`。

### ② 观察：长期名单

1. 打开 **`/watching`（观察）** 或右侧「观察」Tab  
2. 搜索加入要长期看的股票；勾选后点「移除所选」删除（不影响模拟持仓）  
3. 打开列表会自动拉现价等行情，并拉近期**资讯标题**与规则**情绪徽章**（不进 score）；可点表头 **评分** / **量** 排序（再点切换升降）  
4. 点行内「详」看标题列表；打开列表会带上最近一次舆情告警标记（页内告警，无推送）  
5. 「模拟仓位」列显示这只票在假账里的状态：  
   - **未持** → 点 **建仓**，填每只买多少股，看清现价 / 花费 / 剩余现金后确认  
   - **已持 N 股** → 点一下跳到模拟页管理  
6. 要一次进多只，勾选后点表下 **加入纸面**：默认按金额（可切仓位% / 股数），清单里可按只改；确认前仍先看合计花费与剩余现金；标注零成本假设  
7. 确认后，表下 **建仓记录** 按日分组展示（名称 · 股数 · 价 · 金额），与模拟页交易记录同构；无历史流水时用当前持仓兜底

建仓一律按现价假买、不打分，成交后在模拟页持仓标为 **手动**。  
舆情细节见 [sentiment-layer.md](sentiment-layer.md)。

### ③ 对话：解读与问答

- 「茅台现价」→ 行情解读  
- 「分析 ×× 能不能买」→ 深度分析  
- 右侧可对照观察名单与回复 Tab  

### ④ 回溯：历史回测

打开 **`/replay`**，对观察名单跑 Top-K 回测。  
**不必**先有纸面账户。

### ⑤⑥ 纸面 + 模拟：假钱买卖

1. 打开 **`/paper`** 初始化假账（若 `setup_quant` 已做过可跳过）  
2. **`/follow` 模拟** 分三层，按使用频率与「谁做决定」排布：

| 层 | 位置 | 放什么 |
|----|------|--------|
| 主区 | 页面正文 | 净值 · 持仓 · **操作区**（策略调仓 / 资金调整 / 交易记录，同风格卡片） |
| 按需 | 折叠区 | 做 T（预演→确认 · 持仓回测） |

- 本页**不开仓**：新仓只从观察页建仓进来；空持仓时有「去观察建仓」入口  
- 观察页点「已持」会跳到本页并**高亮 / 选中对应持仓行**；清仓 / 加减仓后观察列状态会回写  
- 持仓表上方「出处对照」默认折叠为一行摘要；行内「出处」列同义  
- 表头可按 **市值 / 评分** 排序；点行看单票收盘价曲线，评分列可点看明细  
- 「预演调仓」先出报告，点**确认调仓**才成交；买卖清单由 signal 规则生成，成交后标为「策略」
- 成交成本模型在页顶常显；注资 / 减资 / 回零在「资金调整」区块

`/paper` 是模拟账户的**初始化 / 高级配置**页（不进主导航），日常买卖请用 `/follow` 模拟。

涨跌归因与「不强因子」边界见 [quant-concepts · §4](quant-concepts.md#4-涨跌归因与本系统边界不强因子)。

## 流程速查

| 你想… | 去哪 |
|-------|------|
| 开盘看总账 / 风险 / 净值 | **仪表盘** `/dashboard` |
| 维护观察名单 / 看舆情 | 观察 |
| 给某只票开新仓 | 观察 · 行内「建仓」或勾选后「加入纸面」 |
| 给已有仓位加减仓 / 清仓 | 模拟 · 持仓表 |
| 注资 / 减资 / 回零 | 模拟 · 资金调整 |
| 让规则替我调一次仓 | 模拟 · 策略调仓 → 预演调仓 → 确认调仓（再对照 **历史回测** / **策略中心** 晋升） |
| 验做 T overlay | 模拟 · 做 T 回测；落地则预演→确认做 T |
| 看历史规则是否像样 | **历史回测** · Top-K 回测 / WF |
| 改持仓上限等策略限额 | **策略中心** · 人审晋升（勿在交易页手改） |
| 看回测–纸面拟合 | **系统设置** · 北极星 KPI |
| 初始化 / 重置假账 | `/paper`（进阶；日常用模拟页） |
| 问现价 / 分析 / 对比 | 对话 / 顶栏「AI 助手」 |
| 改选股 β / 启用组 ŷ | `/quant`（研究枢纽；策略中心不改 weights） |

硬刷新避免缓存：静态版本由 `web/asset_version.py` 的 `ASSET_V` 统一注入（见 [quant-ui-standard §4](quant-ui-standard.md#4-静态资源版本单一来源)）。

## 四页主表布局规范

观察 · 模拟 · 策略 · 回溯的主表须保持一致（完整契约见 [quant-ui-standard](quant-ui-standard.md)）：

| 规则 | 要求 |
|------|------|
| 同壳同宽 | 主区 `.page-main` **铺满侧栏右侧**（非 1000px 居中）；六页 + 仪表盘同壳；左右 gutter 仅 `--page-gutter-x`（默认 16px）；页体左右 `padding:0`；表与 wrap 均为 `width: 100%` |
| 无横向滚动 | 容器 `overflow-x: hidden`；禁止用列 `min-width: Nrem` 撑破表 |
| 列宽分配 | `table-layout: fixed` + 百分比列宽；数值列可省略 |
| 股票名 | **至少完整显示前 6 字**，第 7 字起才 `…`；禁止 CSS 再截一层 |
| 贴边留白 | 首列 `padding-left: 18px`，末列 `padding-right: 22px` |
| 模拟持仓 | `.follow-holdings-card` 左右不额外缩进 |

实现落在 `web/static/styles.css`（「四页表格」共用块）。Cursor 规则：`.cursor/rules/investment-table-layout.mdc` · `.cursor/rules/investment-web-ui.mdc`。
