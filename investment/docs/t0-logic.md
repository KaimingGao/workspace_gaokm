# 底仓做 T 产品文档（旗舰选腿：ŷ_oc 破带）

> A 股 T+1 底仓日内往返策略。非实盘、不代客下单，服务于策略验证与纸面增强。

---

## 1. 产品定位与本质

### 1.1 一句话定义

在**已持有的底仓**上，利用日内 5 分钟 K 线的价格波动，条件性地做一笔 **先卖后买（反 T）** 或 **先买后卖（正 T）** 的往返，赚取腿间价差。

### 1.2 与策略调仓的边界

| 维度 | 策略调仓 | 底仓做 T |
|------|----------|----------|
| 决策问题 | 持有什么、每次加几手 | 既有底仓上今天能否用日内波动做往返 |
| 信号头 | y_fuse / y_on ranking · 200/500 股 | 旗舰：每根 5m 用 ŷ_oc 估 C_τ；C>upper 反T、C<lower 正T；leg2=C_τ。ŷ_τw 为五窗相对中位点符号和，过门槛才开 |
| 决策频率 | 每个交易日 09:30 | 每 5 分钟扫至 11:00 |
| 收益类型 | 持有期相对收益 | 已实现 round-trip 价差 |
| 仓位出处 | `origin=strategy` | 做 T leg（`t0_batch`） |
| 分组分档 | 观察池按 `fit_tier` 限制新开/加 | **不看**：做 T 只在已持底仓上 overlay，不吃 ŷ_oo / 拟合档 |

**关键区别**：做 T 不是独立选股 Alpha，而是在调仓给定的底仓上做 **timing overlay**。归因必须分层（调仓 PnL vs 做 T leg）。旗舰选腿用 **ŷ_oc 破带**（C_τ / lower / upper / scale / δ）；**ŷ_τw** 是五窗相对共用中位点（默认 47%）的符号和，作开腿入场。**前序确认已下线**。**阴阳门槛已下线**。**ŷ_oo 不参与**，因此也不套分组 A/B/C 宇宙。

### 1.3 A 股 T+1 硬约束

- **反 T（先卖后买）**：只能卖 **昨日及以前** 买入的可卖旧仓，不能卖当日新买入的仓位。
- **正 T（先买后卖）**：当日买入的新股 T+1 锁定，第二腿只能卖 **旧底仓**，不能卖当日加仓部分。
- 交易必须 **整手（100 股）**，不足 1 手跳过。

## 2. 核心概念

### 2.1 方向（direction）

| 方向 | 内部枚举 | 中文 | 操作 | 适用场景 |
|------|----------|------|------|----------|
| 正 T | `buy_then_sell` | 先买后卖 | 现价加仓 → 触 C_τ / 止损/锁赢/追价卖旧仓 | C<lower（ŷ_oc 估 C_τ） |
| 反 T | `sell_then_buy` | 先卖后买 | 现价卖旧仓 → 触 C_τ / 止损/锁赢/追价买回 | C>upper（ŷ_oc 估 C_τ） |

### 2.2 两腿（leg）

- **Leg1（第一腿 / 触发腿）**：确认根的 **5m 收盘价** 成交。反 T = 卖出；正 T = 买入。
- **Leg2（第二腿 / 平仓腿）**：目标价冻结为 **C_τ**。反 T = 买回；正 T = 卖出旧仓。也可靠止损 / 锁赢 / 午后追价 / 收盘强平。

### 2.3 关键价格锚

| 符号 | 含义 | 来源 |
|------|------|------|
| `ref` | 参考价（默认开盘价） | 日线 open / 分钟首根 open |
| `C_τ` | 目标收盘 | `O×(1+clip(ŷ_oc×scale, y_oc_l, y_oc_u)/100)`，默认 scale=10、l=−3、u=+3 |
| `lower` / `upper` | 破带边 | `C_τ×(1±δ/100)`，默认 δ=0.5%。C>upper 反T；C<lower 正T |
| `ŷ_τw` | 五窗符号和 | `sign(p_up−mid)` 对 ŷ_τ30/45/60/75/90 求和，范围 [−5,+5]；mid 默认 47% |
| `y_tw_enter` | Y_τw入场 | 破带后：正T须 ŷ_τw≥此值；反T须 ŷ_τw≤−此值。默认 2；0=允许 0 票 |
| `y_tw_enter_shares` | Y_τw入场股数 | 过入场未过强：本轮第一腿股数。整百，默认 2000；0=走旧比例仓 |
| `y_tw_strong` | Y_τw强 | 过入场后 \|ŷ_τw\|≥此票用强股数，否则入场股数。默认 2（与入场相同则总用强档） |
| `y_tw_strong_shares` | Y_τw强股数 | 过强：本轮第一腿股数，不少于入场股数。默认 4000 |
| `y_tw_midpoint` | Y_τ*中位点% | 默认 47%。ŷ_τw = 相对中位点的符号数之和 |
| `y_tw_vote_margin` | Y_τ*弃权% | ŷ_τ* 距中位点不超过此百分点则不投票。默认 5 |
| `leg2_target` | 第二腿冻结目标价 | **C_τ** |

## 3. 多层 ŷ 信号体系（dual_y）

做 T 的方向由 ŷ_oc 破带决定，准入另看 ŷ_τw。所有幅度 ŷ 为 **百分点**（ratio × 100），ŷ_τ* 为 **p_up**：

- **主轴**：每根 5m 用 ŷ_oc 估 **C_τ**；C 破 lower/upper 定正/反 T，leg2 冻 C_τ。ŷ_τw = 五窗相对中位点符号和，过 `y_tw_enter`（≥）才开；过 `y_tw_strong` 用强股数，否则入场股数。调仓 ranking 仍是 `y_oo` / `y_trade`（做 T **不吃**）。
- **已下线**：`y_hl` **不参与做 T 选腿**。前序确认 / 阴阳门槛 / 收贴端已下线。`y_cx` · `y_tpd` 验证后暂不用于调仓与做 T。

### 3.2 方向映射（`y_tau_map`，已下线）

v6 正/反 T 由 ŷ_oc 破带决定（§4），ŷ_τw 只作开腿入场。`y_tau_map` 在 `load_t0_rules` 时丢弃。`resolve_dual_y_direction` 单测若直接传入该键，仍按旧表解析：

| 模式 | 规则 |
|------|------|
| `trend`（默认） | `ŷ_τ > 0` → 正 T；`ŷ_τ < 0` → 反 T |
| `fixed_sell_then_buy` | 忽略 ŷ_τ 符号，固定反 T（仍过门槛） |
| `fixed_buy_then_sell` | 忽略 ŷ_τ 符号，固定正 T（仍过门槛） |

### 3.3 准入链（`resolve_dual_y_direction`，库函数）

v6 开腿不走本链。库函数也不再吃 `y_trade` / `y_eod` / nowcast；`load_t0_rules` 仍丢弃这些旧闸键。

顺序固定，任一不满足则跳过：

1. 存在 `y_τ`（方向锚）
2. `|y_τ| ≥ 侧向 y_tau_enter`（库函数显式 cfg；生产 `load_t0_rules` 丢门槛入场键，本步不拦）
3. 可选 `y_gap_tier_*` 跳过与大缺口相悖的方向
4. 正 T 须有现金+仓

`t0_confidence_scale` 固定返回 1.0（目标价不再随 ŷ 缩放）。`y_trade` 幅度下限只留给 `resolve_cover_policy` 强制回补。

### 3.4 因果信息集（防前视）

- **开盘选向**：仅用昨收因子 + 今开缺口（开盘 Z）。
- **确认根重算**：每根 5m 用 **截至该根的前缀分钟** 因果重算 `ŷ_τ` / `ŷ_hl`，再定方向。注入该钟分钟小包与开→τ 截面后，按 `features_tau` **重拆** ŷ_oc（与调仓回测同钟同路径）；扫描 tip 组成 = Ridge 原值。
- **禁止**用全日或未发生分钟做开盘选向。
- 盘后（`eod_next`）决策排除 τ 侧分量，避免 look-ahead。

## 4. 旗舰选腿：ŷ_oc 破带

### 4.1 整体流程

```
每根 5m K（09:30 ~ 11:00）
   │
   ├─ 解析价空间：昨收差 |P_d/P_m−1| 过大则跳过（开盘差已下线）
   ├─ 用截至该根前缀估 ŷ_oc → C_τ = O×(1+clip(ŷ_oc×scale, l, u)/100)
   │     lower = C_τ×(1−δ/100)，upper = C_τ×(1+δ/100)
   ├─ 破带：
   │     C > upper → 反 T（现价卖；leg2=C_τ）
   │     C < lower → 正 T（现价买；leg2=C_τ）
   │     带内 / 缺 ŷ_oc → 跳过
   ├─ ŷ_τw 入场（ŷ_τw = 五窗相对中位点符号和，mid 默认 47%）：
   │     正T须 ŷ_τw≥Y_τw入场；反T须 ŷ_τw≤−入场
   │     过 Y_τw强 → 强股数；否则入场股数
   └─ 通过 → 开一轮（现价成交；第二腿目标=C_τ）
```

### 4.2 价空间对齐（price space）

模型在 **日线空间** 训练，执行在 **分钟价空间** 触价。用缩放因子 `S = O_d / O_m` 对齐：

- 估 C_τ 用日线开；破带比较分钟价空间下的 C_τ_m = C_τ_d / S
- `|P_d / P_m − 1| > t0_price_space_prev_dev_pct`（默认 5%；0=关）→ 跳过（`price_space_mismatch`）
- 开盘差 `|O_d/O_m−1|` 已下线（`t0_price_space_max_dev_pct` 默认 0=关）

### 4.3 方向判定

```python
# C_τ = O×(1+clip(ŷ_oc×scale, y_oc_l, y_oc_u)/100)
# ŷ_τw = sum(sign(p_up−mid)) over ŷ_τ30/45/60/75/90；mid 默认 47%；|p−mid|≤Y_τ*弃权% 不计
if C > C_τ×(1+δ/100) and y_tw <= -enter:  → 反 T，现价卖，leg2=C_τ
if C < C_τ×(1−δ/100) and y_tw >= enter:   → 正 T，现价买，leg2=C_τ
```

默认 `t0_y_oc_target_scale=10`、`t0_y_oc_l=−3`、`t0_y_oc_u=+3`、`t0_close_band_delta_pct=0.5`、`y_tw_enter=2`、`y_tw_strong=2`、`y_tw_enter_shares=2000`、`y_tw_strong_shares=4000`、`y_tw_vote_margin=5`、`y_tw_midpoint=47`。前序确认 / 阴阳门槛 / 收贴端已下线。个股 ŷ_τ* 旁路闸已下线，见 4.6 / 4.7。扫描表 **ŷ_τw 列与跳过原因共用回测落盘票数**，不按当前表单中位点/Y_τ*弃权%重算。

### 4.4 入场门槛（已下线）

`|y_τ|` / `|y_hl|` 入场档不考虑。`y_enter_enabled` / `y_tau_enter` / `y_hl_enter` 及门槛2 对应键在 `load_t0_rules` 丢弃。生产走破带 + ŷ_τw 门槛（缺 ŷ_oc / 缺窗头不开腿）。分钟缺失仍跳过。

Replay 表单：「配置」管本金 / 昨收差%、y_oc 放大 / 下界 / 上界 / 超额带宽δ%、Y_τw入场 / 入场股数、Y_τw强 / 强股数、Y_τ*中位点%、Y_τ*弃权%、最大轮数、止损延迟根+止损%、锁赢%、中点追价与间隔。正/反 T 共用同一套值（保存时写入两侧键）。启用与日分价闸勾选已下线（做 T 常开；价闸由昨收差% 控制，0=关；开盘差已下线）。前序确认 / 阴阳门槛 / 回吐 / 收贴端已下线。股数/票、每轮仓位、满仓上限已从表单下线（虚拟底仓=最大轮数×Y_τw强股数；隐式 `t0_round_ratio=0.4` / `t0_max_position_pct=1.0` 仅在入场/强股数均为 0 时作比例仓回退）。

### 4.5 强信号同号闸（已下线）

`y_hl_strong` 在 `load_t0_rules` 丢弃。y_hl 不再参与做 T 选腿。

### 4.6 ŷ_τc 旁路（已下线）

剩余窗租用已由 ŷ_τ30 / ŷ_τ60 / ŷ_τ90 / ŷ_τw 覆盖。`y_tc_strong` / `y_tc_enter` 在 `load_t0_rules` 丢弃。

### 4.7 ŷ_τ30/45/60/75/90 个股闸 / 入场（已下线）

不考虑单独闸或单独阈值。`y_t*_strong` 与 `y_t*_enter` / `y_t*_enter_alt` 在 `load_t0_rules` 丢弃。生产只走 ŷ_τw 投票门槛。

### 4.8 阴阳门槛 / 前序确认 / 收贴端（已下线）

本根 Close vs Open 闸、前序 ŷ_τw 确认、第一腿 close≥high / close≤low 收贴端、正/反 T 分侧 Y_τw入场均已下线。`t0_bar_oc_gate` / `t0_ytw_prefix_*` / `t0_leg1_close_extreme` / `y_tw_enter_buy_then_sell` / `y_tw_enter_sell_then_buy` 在 `load_t0_rules` 丢弃。历史回放饼图仍可标「K线阴阳逆选向(旧)」或「收在极值未开腿」。

## 5. Leg1 执行

### 5.1 成交价

Leg1 以 **确认根的 5m 收盘价** 成交（`fill_sell = close` / `fill_buy = close`）。不再使用相对开盘的触发百分比。

### 5.2 多轮开仓（slots）

- 每轮股数：过 Y_τw入场未过强用 `y_tw_enter_shares`（默认 2000）；过 Y_τw强用 `y_tw_strong_shares`（默认 4000，≥入场股数）。两边都为 0 时回退 `t0_round_ratio`（默认 0.4）
- 最多 `t0_slots_max_rounds` 轮（默认 5），累计不超过 `t0_max_position_pct`（默认 1.0；表单已下线，隐式满仓）
- 每轮独立冻结 leg2 目标，各轮 leg1 / leg2 独立配对
- **11:00 后不开新 leg1**（`T0_LAST_LEG1_HM = "11:00"`），午后只处理已开仓的 leg2

### 5.3 现金与可卖约束

- 反 T leg1 卖出受剩余 **可卖旧仓** 约束
- 正 T leg1 买入受 **账户现金** 约束（含手续费）；第二腿仍卖旧仓，开新轮前预扣已承诺回补额度
- 不足整手时本轮跳过
- 日终按墙钟重放：现金/可卖不够时丢掉 **最晚开** 的一轮，不撤已成交的第一笔

### 5.4 冻结本轮（`freeze_round`）

Leg1 成交瞬间冻结方向、成交价与 **C_τ**（`leg2_target`）。第二腿优先触 C_τ；也可靠止损 / 锁赢 / 午后追价 / 收盘强平。

## 6. Leg2 执行

### 6.1 目标价优先级

冻结目标为 **C_τ**。盘中可触 C_τ / 止损 / 锁赢；午后中点追价以 C_τ 与现价中点为种子；收盘强平。

### 6.2 τ 出场价闸（`tau_exit_bound_px`）

公式：

```
move_pct = clamp(ŷ_τ × mult, move_min, move_max) + bias
bound = ref × (1 + move_pct / 100)
```

| 参数 | 默认（正 T / 反 T） | 说明 |
|------|---------------------|------|
| `mult` | 1.0 / 1.0 | 裕度乘数 |
| `bias` | +1.0 / −1.0 | 百分点偏移 |
| `move_min/move_max` | ±100 | clamp 范围 |
| `skip` | True | 闸开关 |

**方向条件**：

- 正 T（卖旧仓）：`fill_px > bound`（卖价须高于 bound）
- 反 T（买回）：`fill_px < bound`（买价须低于 bound）

### 6.3 午后追价（PM chase）

到 `t0_pm_degrade`（默认 13:00）后：

- **禁开新 leg1**
- 已开未平的 leg2 启用 **中点追价**：`新目标 = (旧目标 + 现价) / 2`
- 每 `t0_pm_chase_interval_min`（默认 5 分钟）调整一次
- 追价有上下限保护：
  - 反 T 追买上限 `≤ leg1 卖价`（`t0_pm_chase_cap_leg1_sell_then_buy`）
  - 正 T 追卖下限 `≥ leg1 买价`（`t0_pm_chase_cap_leg1_buy_then_sell`）
  - `must_cover_same_day=True` 时强制生效

### 6.4 止损

| 方向 | 止损条件 | 配置 |
|------|----------|------|
| 正 T | 跌破 `买价 × (1 − stop_pct%)` | `t0_stop_pct_buy_then_sell`（默认 1.2%） |
| 反 T | 涨破 `卖价 × (1 + stop_pct%)` | `t0_stop_pct_sell_then_buy`（默认 1.2%） |

- 延迟 `t0_stop_arm_bars`（默认 1 根）后生效
- 止损固定收盘破线确认（`t0_stop_on_close=True`，表单不再提供开关）
- 止损 leg2 不受 τ 出场价闸约束

### 6.4b 锁赢（提前第二腿）

止损看亏：正 T 跌破买价、反 T 涨破卖价。锁赢方向相反：收益达到此%则提前做第二腿（不必等 C_τ）。

| 方向 | 触发（收盘确认） | 配置 |
|------|------------------|------|
| 正 T | 收盘 ≥ `买价 × (1 + lock%)` | `t0_lock_win_pct_buy_then_sell`（默认 2%） |
| 反 T | 收盘 ≤ `卖价 × (1 − lock%)` | `t0_lock_win_pct_sell_then_buy`（默认 2%） |

- `lock_win_pct=0` 关闭该侧
- 延迟根与止损共用 `t0_stop_arm_bars`
- 本根已触 C_τ 不抢（走目标腿）
- 成交填收盘价，`leg_kind=lock_win`，不受 τ 出场价闸约束

优先级：止损 → 锁赢 → 触 C_τ / 中点追价 → 收盘强平。

### 6.5 收盘强平 / 敞口

收盘窗（末根 ≥ 14:55）时 leg2 未平。表单「当日回补」已下线，生产强制回补。

| `must_cover_same_day` | 行为 |
|------------------------|------|
| `True`（默认 / 表单常开） | 用末根 5m 收盘价强制买回/卖回；现金不足则记 `abandon_cover_cash` 敞口 |
| `False` | 仅显式 cfg：记 `abandon_cover` 敞口（`exposure_pnl`） |

- 强平价用 **末根 5m 收盘价**，不用日线收盘价
- 盘中前缀（`defer_eod=True`）未完记 `defer_eod_pending`，不计敞口

## 9. 回测框架

### 9.1 数据要求

- **必须有 5 分钟 K 线**，缺分钟线的交易日 **整段跳过**（不回退日线模拟）
- 分钟线 ≥ 2 根才进入路径（slots 模式 ≥ 1 根）
- 5m 数据拉取有 18 秒超时保护，失败回退无分钟 + 跳过

### 9.2 路径模式

统一 `path_mode=first_touch`：按分钟时间序 **第一触达** 成交，不再使用日线 high/low 代理。

### 9.3 跳过类别

| 类别 | 原因 |
|------|------|
| `missing_minute` | 缺分钟线 |
| `signal_skip` | 未过 ŷ 入场门槛 / 破带未成立 |
| `coupling_skip` | stance 耦合不允许做 T |
| `t_plus_one` | 可卖旧仓不足 1 手 |
| `intraday_legs_open` | 盘中已有成交腿，整单回放防重复 |
| `price_space_mismatch` | 日/分钟开盘偏差超阈 |

### 9.4 高/低 ≈ 低（涨停/跌停无波动）的票跳过

`simulate_t0_day` 中 `high ≈ low` 的票不做 T。

### 9.5 虚拟仓与本金

`/replay` 做 T 回测只用纸面股票名单；仓位/本金走表单「配置」：

- **Y_τw强股数** 默认 4000；回测虚拟底仓=`最大轮数 × max(入场股数, 强股数)`（默认 5×4000=20000；`initial_shares`）
- **本金** 默认 20 万（`initial_cash`），也是累计收益比例的分母
- 不写账本；保存规则不改本金

### 9.6 截面因子（拟合 = 回测 = live）

ŷ 截面（`sector_ret_to_tau` / `sector_ret_last_*`）与训练 ``attach_cross_section_breadth`` 同一口径：

- 宇宙 = 纸面持仓 ∪ 观察池（上限 = `WATCHING_MAX_SIZE`，默认 200）
- 板块中位对宇宙 **全员** 取中位（不再截 24 只）
- 每个 `(日期, τ)`：一次扫池同时写出开→τ 与 30/45/60/75/90m 中位，后续头读缓存
- live 盯盘与做 T 回测都把该宇宙的 5m 灌进同伴仓；持仓回测灌一次后复用，不清仓重灌
- 持仓只决定谁成交，不决定截面宽度

权重仍分研究套 / 执行套；因子管子三路同一。

## 10. 纸面与实盘执行

### 10.1 纸面持仓做 T

`simulate_t0_on_holdings` 对纸面持仓逐票跑单日做 T：

- 按股票代码排序，共享现金池，执行序确定可复现
- T+1 按「当前交易会话日」解冻可卖量
- `dry_run=True` 只返回预演结果，不改 paper
- 成交腿写入 `paper.trades`，记 `origin=t0`
- 操作日志记 `t0_batch`

### 10.2 盘中 Worker

- `auto_worker.py` / `intraday.py`：每 5 分钟（`T0_INTRADAY_TICK_SEC = 300s`）轮询
- 分钟缓存 TTL 5 小时，lookback 5 天；截面 5m 灌观察池 ∪ 持仓（与回测 / 拟合同宇宙）
- 盘中前缀 `defer_eod=True`，避免半日分钟误强平
- 已落账腿的代码在整单回放时跳过（防重复）

### 10.3 stance 耦合

`coupling.t0_vs_stance` 控制做 T 与调仓 stance 的关系：

- `independent`（默认）：互不影响
- `avoid`：该 stance 下跳过做 T

## 13. 已下线设计（避免误用）

以下旧机制已在 v6 下线，配置中残留会被 `drop_dead_t0_keys` 丢弃：

- 相对开盘的 leg1 触发百分比（`buy_trigger_pct_*` / `sell_trigger_pct_*`）
- τ 入场价闸（`y_tau_entry_price_*`）—— leg1 改为确认根收盘
- 前缀阴阳占比确认（`y_prefix_*`）
- 自极值回吐（`t0_giveback_*`）—— 改为相对第一腿成交价的锁赢%
- 复合确认 / 环境闸选腿（`t0_confirm_*` / `t0_env_*`）
- y_path 放弃（`y_path_abandon_*`）
- score 先验平移带宽（`y_tau_leg1_prior_*`）—— 改为 clip 估 C_τ + 对称 ±δ
- `y_tau_map` 符号选向、缺口档 `y_gap_tier_*`、振幅下限 `min_range_pct*`、ATR 触发、trade/eod 强闸、nowcast 异号闸、ŷ 缩放目标价 —— v6 开腿只看收盘带宽 + 入场门槛 / 旁路；`resolve_dual_y_direction` / `t0_confidence_scale` 也不再执行这些闸
