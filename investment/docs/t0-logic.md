# 底仓做 T 产品文档（v6 收盘带宽）

> A 股 T+1 底仓日内往返策略。非实盘、不代客下单，服务于策略验证与纸面增强。

---

## 1. 产品定位与本质

### 1.1 一句话定义

在**已持有的底仓**上，利用日内 5 分钟 K 线的价格波动，条件性地做一笔 **先卖后买（反 T）** 或 **先买后卖（正 T）** 的往返，赚取腿间价差。

### 1.2 与策略调仓的边界

| 维度 | 策略调仓 | 底仓做 T |
|------|----------|----------|
| 决策问题 | 持有什么、每次加几手 | 既有底仓上今天能否用日内波动做往返 |
| 信号头 | y_fuse / y_on ranking · 200/500 股 | v6：ŷ_oc clip 估 C_τ，收价相对 C_τ×(1±δ) 选向；leg2 冻结 C_τ |
| 决策频率 | 每个交易日 09:30 | 每 5 分钟扫至 11:00 |
| 收益类型 | 持有期相对收益 | 已实现 round-trip 价差 |
| 仓位出处 | `origin=strategy` | 做 T leg（`t0_batch`） |
| 分组分档 | 观察池按 `fit_tier` 限制新开/加 | **不看**：做 T 只在已持底仓上 overlay，不吃 ŷ_oo / 拟合档 |

**关键区别**：做 T 不是独立选股 Alpha，而是在调仓给定的底仓上做 **timing overlay**。归因必须分层（调仓 PnL vs 做 T leg）。v6 估 C_τ / 选腿用 ŷ_oc；**ŷ_oo 不参与**，因此也不套分组 A/B/C 宇宙。

### 1.3 A 股 T+1 硬约束

- **反 T（先卖后买）**：只能卖 **昨日及以前** 买入的可卖旧仓，不能卖当日新买入的仓位。
- **正 T（先买后卖）**：当日买入的新股 T+1 锁定，第二腿只能卖 **旧底仓**，不能卖当日加仓部分。
- 交易必须 **整手（100 股）**，不足 1 手跳过。

## 2. 核心概念

### 2.1 方向（direction）

| 方向 | 内部枚举 | 中文 | 操作 | 适用场景 |
|------|----------|------|------|----------|
| 正 T | `buy_then_sell` | 先买后卖 | 现价加仓 → 冲高卖旧仓 | C 低于 C_τ×(1−δ) |
| 反 T | `sell_then_buy` | 先卖后买 | 现价卖旧仓 → 回落买回 | C 高于 C_τ×(1+δ) |

### 2.2 两腿（leg）

- **Leg1（第一腿 / 触发腿）**：确认根的 **5m 收盘价** 成交。反 T = 卖出；正 T = 买入。
- **Leg2（第二腿 / 平仓腿）**：盘中分钟第一触达目标价成交。反 T = 买回；正 T = 卖出旧仓。

### 2.3 关键价格锚

| 符号 | 含义 | 来源 |
|------|------|------|
| `ref` | 参考价（默认开盘价） | 日线 open / 分钟首根 open |
| `C_τ`（`close_px`） | 目标交易价 | `C_τ = O × (1 + clip(ŷ_oc × scale, y_oc_l, y_oc_u) / 100)`（默认 scale=10，clip ±3；ŷ_τc 不参与） |
| `δ`（`delta_pct`） | 超额带宽 | `upper = C_τ×(1+δ/100)`，`lower = C_τ×(1−δ/100)`；默认 3 |
| `leg2_target` | 第二腿冻结目标价 | **C_τ** |

## 3. 多层 ŷ 信号体系（dual_y）

做 T 的方向与准入由多层预测分数联合决定。所有 ŷ 均为 **百分点**（ratio × 100），但角色不同：

- **主轴**：`ŷ_oc` 估 C_τ（clip 后），超额 r=(C/C_τ−1)% 相对 ±δ 选向；调仓 ranking 仍是 `y_oo` / `y_trade`（做 T **不吃**）。
- **形状**：`y_hl`（旧键 `y_path`）做 T **同号闸 + 入场**；`y_cx` · `y_tpd` 验证后暂不用于调仓与做 T。旧 overlay `y_path_*` 在 `load_t0_rules` 迁到 `y_hl_*` 后再丢。

### 3.1 各 ŷ 角色

| ŷ | 标签 | 含义 | 在做 T 中的作用 |
|----|------|------|-----------------|
| `y_trade` | 日频交易分数 | 横截面排序主信号 | **已下线**：不进估 C_τ / 选腿 / 表列（`load_t0_rules` 丢强闸；库函数选向也不再作闸） |
| `y_eod` | 旧日收收益头 | 已迁为调仓 **ŷ_oo** | **已下线**：不进估 C_τ / 选腿 / 表列 / tip（`load_t0_rules` 丢 `y_eod_*`；库函数选向也不再作闸） |
| **`y_τ`** | 盘中 τ 收益 | open→close（开盘口径，OC 拟合） | **估 C_τ**；门槛 \|y_τ\| 入场 |
| `y_hl` | 分钟极值序 | signed range%（旧键 `y_path`） | **同号闸 + 入场**：`|y_hl|>y_hl_strong` 须与 y_τ 同号；门槛 `|y_hl|`（默认 0=关）。缺分不拦（`y_hl_required` 除外）。不进调仓 ranking |
| `y_nowcast` | 即时对照 | 盘中剩余收益 | **不参与**估 C_τ 与选腿 |

| `y_tpd` | 分钟K形状旁路 | 转折点密度 TPD∈[0,1] | **已下线**：不进调仓 / 做 T 闸 / 表列 |

| **`y_τ45`** | τ→τ⊕45m | 同 ŷ_τ30（窗 `mean(price(τ⊕40/45/50))`） | 同语义（只进 ŷ_τw 投票）。14:10 后不足 50 交易分钟不出分 |
| **`y_τ60`** | τ→τ⊕60m | live=`P(窗收益>0)`；真实仍 `mean(price(τ⊕55/60/65))/price(τ)−1` | 同 ŷ_τ30 语义。14:00 后不足 65 交易分钟不出分 |
| **`y_τ75`** | τ→τ⊕75m | 同 ŷ_τ30（窗 `mean(price(τ⊕70/75/80))`） | 同语义。13:40 后不足 80 交易分钟不出分 |
| **`y_τ90`** | τ→τ⊕90m | live=`P(窗收益>0)`；真实仍 `mean(price(τ⊕85/90/95))/price(τ)−1` | 同 ŷ_τ30 语义。13:30 后不足 95 交易分钟不出分 |

### 3.2 方向映射（`y_tau_map`，已下线）

v6 选正/反 T **只看** C 相对 C_τ 的 ±δ 破带（§4）。`y_tau_map` 在 `load_t0_rules` 时丢弃，不改破带结果。`resolve_dual_y_direction` 单测若直接传入该键，仍按旧表解析：

| 模式 | 规则 |
|------|------|
| `trend`（默认） | `ŷ_τ > 0` → 正 T；`ŷ_τ < 0` → 反 T |
| `fixed_sell_then_buy` | 忽略 ŷ_τ 符号，固定反 T（仍过门槛） |
| `fixed_buy_then_sell` | 忽略 ŷ_τ 符号，固定正 T（仍过门槛） |

### 3.3 准入链（`resolve_dual_y_direction`，库函数）

v6 开腿不走本链。库函数也不再吃 `y_trade` / `y_eod` / nowcast；`load_t0_rules` 仍丢弃这些旧闸键。

顺序固定，任一不满足则跳过：

1. 存在 `y_τ`（方向锚）
2. `|y_τ| ≥ 侧向 y_tau_enter`（库函数显式 cfg；生产 `load_t0_rules` 丢门槛入场键，本步不拦）
3. 可选 `y_gap_tier_*` 跳过与大缺口相悖的方向
4. 正 T 须有现金+仓

`t0_confidence_scale` 固定返回 1.0（目标价不再随 ŷ 缩放）。`y_trade` 幅度下限只留给 `resolve_cover_policy` 强制回补。

### 3.4 因果信息集（防前视）

- **开盘选向**：仅用昨收因子 + 今开缺口（开盘 Z）。
- **确认根重算**：每根 5m 用 **截至该根的前缀分钟** 因果重算 `ŷ_τ` / `ŷ_hl`，再定方向。
- **禁止**用全日或未发生分钟做开盘选向。
- 盘后（`eod_next`）决策排除 τ 侧分量，避免 look-ahead。

## 4. v6 收盘带宽选腿（核心入场机制）

### 4.1 整体流程

```
每根 5m K（09:35 ~ 11:00）
   │
   ├─ 解析价空间 S = O_d / O_m
   ├─ 用前缀 ŷ_oc 估 C_τ = O×(1+clip(ŷ_oc×scale, y_oc_l, y_oc_u)/100)
   ├─ 超额 r = (C/C_τ−1)×100 相对对称 ±δ：
   │     r > +δ  → 反 T（现价卖；leg2=C_τ）
   │     r < −δ  → 正 T（现价买；leg2=C_τ）
   │     带内      → 跳过
   ├─ 入场门槛已下线（|ŷ_oc| / |y_hl| 档不拦；分钟缺失仍跳过）
   ├─ ŷ_τw 旁路：|ŷ_τw| **大于** `y_tw_strong` 且逆带 → 跳过（`>=5` 关闸；默认 5=关；票=sign(p_up−0.5)；|p−0.5|≤`y_tw_vote_margin` 弃权，默认 2pp）
   └─ 通过 → 开一轮（现价成交；freeze 目标价 = C_τ）
```

### 4.2 价空间对齐（price space）

模型在 **日线空间** 训练（open→close），执行在 **分钟价空间** 触价。用缩放因子 `S = O_d / O_m` 对齐：

- 估 C_τ 用日线 open（与训标签同空间）
- 破带比较本根 5m 收价 C
- `|S − 1| > t0_price_space_max_dev_pct`（默认 5%）→ 跳过（`price_space_mismatch`）

### 4.3 方向判定

```python
# r、δ、ŷ_oc、clip 沿均为百分点；price = 开盘 O
C_τ = O * (1 + clip(y_oc * scale, y_oc_l, y_oc_u) / 100)
r = (C / C_τ - 1) * 100
if r > +δ:   → 反 T，现价卖，leg2 = C_τ
if r < −δ:   → 正 T，现价买，leg2 = C_τ
```

ŷ_τc **不参与**估 C_τ / 选向 / 目标价。默认 scale=10、y_oc_l=−3、y_oc_u=+3、δ=3。个股 ŷ_τ* 旁路闸已下线，见 4.6 / 4.7。

### 4.4 入场门槛（已下线）

`|y_τ|` / `|y_hl|` 入场档不考虑。`y_enter_enabled` / `y_tau_enter` / `y_hl_enter` 及门槛2 对应键在 `load_t0_rules` 丢弃。生产过破带后只走 HL 同号闸与 ŷ_τw 旁路。`close_band_enter_skip_reason` 仅供显式 cfg 单测；分钟缺失仍跳过。

Replay 表单：「共用」管本金 / 仓位 / 开盘差·昨收差%，以及 C_τ 放大/clip、超额带宽 δ%、HL强%、τw强、弃权%。启用与日分价闸勾选已下线（做 T 常开；价闸由开盘差%/昨收差% 控制，0=关）。

### 4.5 强信号同号闸（`close_band_sign_skip_reason`）

`|y_hl| > y_hl_strong`（默认 5%；`≤0` 则任意非零都要求同号）须与 y_τ 同号，异号跳过。无 y_hl 时同号闸不拦。旧键 `y_path_strong` 加载时迁到 `y_hl_strong`。

### 4.6 ŷ_τc 旁路（已下线）

剩余窗租用已由 ŷ_τ30 / ŷ_τ60 / ŷ_τ90 / ŷ_τw 覆盖。`close_band_y_tc_skip_reason` 恒不跳过；`y_tc_strong` / `y_tc_enter` 在 `load_t0_rules` 丢弃。

### 4.7 ŷ_τ30/45/60/75/90 个股闸 / 入场（已下线）

不考虑单独闸或单独阈值。`y_t*_strong` 与 `y_t*_enter` / `y_t*_enter_alt` 在 `load_t0_rules` 丢弃（缺键=关）。生产只走 ŷ_τw 投票。`close_band_y_t*_skip_reason` / 入场 p_agree 仅供显式 cfg 单测。

## 5. Leg1 执行

### 5.1 成交价

Leg1 以 **确认根的 5m 收盘价** 成交（`fill_sell = close` / `fill_buy = close`）。不再使用相对开盘的触发百分比。

### 5.2 多轮开仓（slots）

- 每轮仓位 `ratio = t0_round_ratio`（默认 0.4，即 40% 可卖量）
- 最多 `t0_slots_max_rounds` 轮（默认 5），累计不超过 `t0_max_position_pct`（默认 1.0）
- 每轮独立冻结 leg2 目标，各轮 leg1 / leg2 独立配对
- **11:00 后不开新 leg1**（`T0_LAST_LEG1_HM = "11:00"`），午后只处理已开仓的 leg2

### 5.3 现金与可卖约束

- 反 T leg1 卖出受剩余 **可卖旧仓** 约束
- 正 T leg1 买入受 **账户现金** 约束（含手续费）；第二腿仍卖旧仓，开新轮前预扣已承诺回补额度
- 不足整手时本轮跳过
- 日终按墙钟重放：现金/可卖不够时丢掉 **最晚开** 的一轮，不撤已成交的第一笔

### 5.4 冻结第二腿目标（`freeze_round`）

Leg1 成交瞬间冻结本轮参数：

| 方向 | leg2_target |
|------|-------------|
| 正 T | C_τ |
| 反 T | C_τ |

冻结后 leg2 目标价不再随后续 ŷ 变化。

## 6. Leg2 执行

### 6.1 目标价优先级

Leg2 的触发目标价按以下优先级确定：

1. **冻结目标交易价**（`leg2_target_px`）：leg1 成交时冻结的 `C_τ`
2. **τ 出场价闸**：`bound = open × (1 + ŷ_τ × mult / 100 + bias)`，无冻结目标时回退
3. **平盘线**：以 leg1 成交价为目标（缺 ŷ_τ 时）

### 6.2 τ 出场价闸（`tau_exit_bound_px`）

公式：

```
move_pct = clamp(ŷ_τ × mult, move_min, move_max) + bias
bound = ref × (1 + move_pct / 100)
```

| 参数 | 默认（正 T / 反 T） | 说明 |
|------|---------------------|------|
| `mult` | 1.0 / 1.0 | 裕度乘数 |
| `bias` | +1.0 / −1.0 | 百分点偏移 |
| `move_min/move_max` | ±100 | clamp 范围 |
| `skip` | True | 闸开关 |

**方向条件**：

- 正 T（卖旧仓）：`fill_px > bound`（卖价须高于 bound）
- 反 T（买回）：`fill_px < bound`（买价须低于 bound）

### 6.3 午后追价（PM chase）

到 `t0_pm_degrade`（默认 13:00）后：

- **禁开新 leg1**
- 已开未平的 leg2 启用 **中点追价**：`新目标 = (旧目标 + 现价) / 2`
- 每 `t0_pm_chase_interval_min`（默认 5 分钟）调整一次
- 追价有上下限保护：
  - 反 T 追买上限 `≤ leg1 卖价`（`t0_pm_chase_cap_leg1_sell_then_buy`）
  - 正 T 追卖下限 `≥ leg1 买价`（`t0_pm_chase_cap_leg1_buy_then_sell`）
  - `must_cover_same_day=True` 时强制生效

### 6.4 止损

| 方向 | 止损条件 | 配置 |
|------|----------|------|
| 正 T | 跌破 `买价 × (1 − stop_pct%)` | `t0_stop_pct_buy_then_sell`（默认 1.2%） |
| 反 T | 涨破 `卖价 × (1 + stop_pct%)` | `t0_stop_pct_sell_then_buy`（默认 1.2%） |

- 延迟 `t0_stop_arm_bars`（默认 1 根）后生效
- 止损固定收盘破线确认（`t0_stop_on_close=True`，表单不再提供开关）
- 止损 leg2 不受 τ 出场价闸约束

### 6.4b 自极值回吐（提前第二腿）

硬止损只看第一腿成交价。正 T 加仓后若先冲高、再回撤但未跌破买价，在碰到 C_τ 或 13:00 中点追价之前不会卖旧仓，浮盈会被吐光。回吐在 **午后追价起算之前** 用盘中极值锁盈：

| 方向 | 激活 | 触发（收盘确认） | 配置 |
|------|------|------------------|------|
| 正 T | 入场后高点 ≥ `买价 × (1 + arm%)` | 收盘 ≤ `高点 × (1 − giveback%)` 且仍 ≥ 买价 | `t0_giveback_pct_buy_then_sell`（默认 0.6%） |
| 反 T | 入场后低点 ≤ `卖价 × (1 − arm%)` | 收盘 ≥ `低点 × (1 + giveback%)` 且仍 ≤ 卖价 | `t0_giveback_pct_sell_then_buy`（默认 0.6%） |

- 共用激活幅度 `t0_giveback_arm_pct`（默认 0.4%；0=不要求涨跌幅）
- `giveback_pct=0` 关闭该侧
- 延迟根与止损共用 `t0_stop_arm_bars`
- 本根已触达冻结 C_τ 则不抢，仍走目标腿
- 午后 `t0_pm_degrade` 之后不走回吐，改中点追价
- 回吐成交填收盘价，`leg_kind=giveback`，不受 τ 出场价闸约束

优先级：止损 → 本根已触 C_τ 则走目标腿，否则回吐 → 中点追价 → 收盘强平。

### 6.5 收盘强平 / 敞口

收盘窗（末根 ≥ 14:55）时 leg2 未平。表单「当日回补」已下线，生产强制回补。

| `must_cover_same_day` | 行为 |
|------------------------|------|
| `True`（默认 / 表单常开） | 用末根 5m 收盘价强制买回/卖回；现金不足则记 `abandon_cover_cash` 敞口 |
| `False` | 仅显式 cfg：记 `abandon_cover` 敞口（`exposure_pnl`） |

- 强平价用 **末根 5m 收盘价**，不用日线收盘价
- 盘中前缀（`defer_eod=True`）未完记 `defer_eod_pending`，不计敞口

## 7. 成交模式（fill_mode）

| 模式 | 卖出成交价 | 买入成交价 |
|------|-----------|-----------|
| `trigger`（默认） | 触发价（目标价） | 触发价（目标价） |
| `mid` | `(high + sell_level) / 2` | `(low + buy_level) / 2` |
| `optimistic` | 当根 high | 当根 low |

可分侧配置 `fill_mode_sell_then_buy` / `fill_mode_buy_then_sell`。

## 9. 回测框架

### 9.1 数据要求

- **必须有 5 分钟 K 线**，缺分钟线的交易日 **整段跳过**（不回退日线模拟）
- 分钟线 ≥ 2 根才进入路径（slots 模式 ≥ 1 根）
- 5m 数据拉取有 18 秒超时保护，失败回退无分钟 + 跳过

### 9.2 路径模式

统一 `path_mode=first_touch`：按分钟时间序 **第一触达** 成交，不再使用日线 high/low 代理。

### 9.3 跳过类别

| 类别 | 原因 |
|------|------|
| `missing_minute` | 缺分钟线 |
| `signal_skip` | 未过 ŷ 入场门槛 / 破带未成立 |
| `coupling_skip` | stance 耦合不允许做 T |
| `t_plus_one` | 可卖旧仓不足 1 手 |
| `intraday_legs_open` | 盘中已有成交腿，整单回放防重复 |
| `price_space_mismatch` | 日/分钟开盘偏差超阈 |

### 9.4 高/低 ≈ 低（涨停/跌停无波动）的票跳过

`simulate_t0_day` 中 `high ≈ low` 的票不做 T。

### 9.5 虚拟仓与本金

`/replay` 做 T 回测只用纸面股票名单；仓位/本金走表单「共用」：

- **股数/票** 默认 1000（`initial_shares`）
- **本金** 默认 20 万（`initial_cash`），也是累计收益比例的分母
- 不写账本；保存规则不改这两项

### 9.6 截面因子（拟合 = 回测 = live）

ŷ 截面（`sector_ret_to_tau` / `sector_ret_last_*`）与训练 ``attach_cross_section_breadth`` 同一口径：

- 宇宙 = 纸面持仓 ∪ 观察池（上限 = `WATCHING_MAX_SIZE`，默认 200）
- 板块中位对宇宙 **全员** 取中位（不再截 24 只）
- 每个 `(日期, τ)`：一次扫池同时写出开→τ 与 30/45/60/75/90m 中位，后续头读缓存
- live 盯盘与做 T 回测都把该宇宙的 5m 灌进同伴仓；持仓回测灌一次后复用，不清仓重灌
- 持仓只决定谁成交，不决定截面宽度

权重仍分研究套 / 执行套；因子管子三路同一。

## 10. 纸面与实盘执行

### 10.1 纸面持仓做 T

`simulate_t0_on_holdings` 对纸面持仓逐票跑单日做 T：

- 按股票代码排序，共享现金池，执行序确定可复现
- T+1 按「当前交易会话日」解冻可卖量
- `dry_run=True` 只返回预演结果，不改 paper
- 成交腿写入 `paper.trades`，记 `origin=t0`
- 操作日志记 `t0_batch`

### 10.2 盘中 Worker

- `auto_worker.py` / `intraday.py`：每 5 分钟（`T0_INTRADAY_TICK_SEC = 300s`）轮询
- 分钟缓存 TTL 5 小时，lookback 5 天；截面 5m 灌观察池 ∪ 持仓（与回测 / 拟合同宇宙）
- 盘中前缀 `defer_eod=True`，避免半日分钟误强平
- 已落账腿的代码在整单回放时跳过（防重复）

### 10.3 stance 耦合

`coupling.t0_vs_stance` 控制做 T 与调仓 stance 的关系：

- `independent`（默认）：互不影响
- `avoid`：该 stance 下跳过做 T
